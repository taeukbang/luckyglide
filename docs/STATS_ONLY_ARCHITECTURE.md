## 🗄️ 초경량 테이블 구조

```sql
-- 파트너별 일일 마이링크 생성 통계
CREATE TABLE public.partner_mylink_stats (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  partner_id text NOT NULL,              -- 파트너 식별자
  date date NOT NULL,                    -- 날짜 (KST 기준)
  count int NOT NULL DEFAULT 0,          -- 생성 개수
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  
  -- 파트너 + 날짜 조합은 유니크
  UNIQUE(partner_id, date)
);

-- 빠른 조회를 위한 인덱스
CREATE INDEX idx_partner_stats_lookup 
  ON partner_mylink_stats (partner_id, date DESC);
```

**테이블 크기 예상:**
- 1개 row = ~100 bytes
- 파트너 10개 × 365일 = 3,650 rows/년
- 연간 용량: **~365KB** (초경량!)

### 2️⃣ Supabase 함수: 카운터 증가 (원자적)

```sql
-- Supabase SQL Editor에서 실행
CREATE OR REPLACE FUNCTION increment_mylink_count(
  p_partner_id text,
  p_date date
) RETURNS void AS $$
BEGIN
  INSERT INTO partner_mylink_stats (partner_id, date, count, updated_at)
  VALUES (p_partner_id, p_date, 1, NOW())
  ON CONFLICT (partner_id, date)
  DO UPDATE SET 
    count = partner_mylink_stats.count + 1,
    updated_at = NOW();
END;
$$ LANGUAGE plpgsql;
```

**장점:**
- ✅ 원자적(atomic) 증가 (동시성 안전)
- ✅ 빠른 실행 (~1ms)
- ✅ 사용자 응답 시간에 영향 없음

## 📊 통계 조회 API

### API 엔드포인트

```typescript
// api/stats/mylink-daily.ts

export default async function handler(req: Request): Promise<Response> {
  const { searchParams } = new URL(req.url);
  const partnerId = searchParams.get("partnerId");
  const startDate = searchParams.get("startDate"); // YYYY-MM-DD
  const endDate = searchParams.get("endDate");     // YYYY-MM-DD
  
  const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);
  
  let query = supabase
    .from("partner_mylink_stats")
    .select("date, count")
    .eq("partner_id", partnerId)
    .order("date", { ascending: false });
  
  if (startDate) query = query.gte("date", startDate);
  if (endDate) query = query.lte("date", endDate);
  
  const { data, error } = await query;
  
  if (error) {
    return json({ error: error.message }, 500);
  }
  
  return json({
    partner_id: partnerId,
    period: { start: startDate, end: endDate },
    total: data.reduce((sum, d) => sum + d.count, 0),
    daily: data
  });
}
```

## 📈 통계 활용

### 1. 파트너별 일일 사용량

```sql
-- 최근 30일 일별 사용량
SELECT 
  date,
  count,
  CASE 
    WHEN LAG(count) OVER (ORDER BY date) IS NULL THEN 0
    ELSE count - LAG(count) OVER (ORDER BY date)
  END as daily_change
FROM partner_mylink_stats
WHERE partner_id = 'test-partner'
  AND date >= CURRENT_DATE - INTERVAL '30 days'
ORDER BY date DESC;
```

### 2. 전체 파트너 비교

```sql
-- 이번 달 파트너별 총 사용량
SELECT 
  partner_id,
  SUM(count) as total_count,
  AVG(count) as avg_daily,
  MAX(count) as peak_daily
FROM partner_mylink_stats
WHERE date >= DATE_TRUNC('month', CURRENT_DATE)
GROUP BY partner_id
ORDER BY total_count DESC;
```

### 3. 시간대별 추세

```sql
-- 요일별 평균 사용량
SELECT 
  TO_CHAR(date, 'Day') as day_of_week,
  ROUND(AVG(count)) as avg_count
FROM partner_mylink_stats
WHERE partner_id = 'test-partner'
  AND date >= CURRENT_DATE - INTERVAL '90 days'
GROUP BY TO_CHAR(date, 'Day'), EXTRACT(DOW FROM date)
ORDER BY EXTRACT(DOW FROM date);
```
